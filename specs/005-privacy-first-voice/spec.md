# Private full-duplex speech

## Goal
Support configurable self-hosted STT/TTS with consent.

## Acceptance criteria
- [ ] Private speech does not use browser cloud providers
- [ ] Audio retention is configurable and testable

## Non-goals
Unrelated changes and silent upstream API modifications.
